# Physical AI & Humanoid Robotics Textbook

A comprehensive Docusaurus-based textbook for Physical AI & Humanoid Robotics, covering ROS 2, Gazebo, Unity, NVIDIA Isaac, and Vision-Language-Action (VLA) systems.

## Overview

This textbook provides comprehensive coverage of:
- Module 1: The Robotic Nervous System (ROS 2)
- Module 2: The Digital Twin (Gazebo & Unity)
- Module 3: The AI-Robot Brain (NVIDIA Isaac)
- Module 4: Vision-Language-Action (VLA)

## Features

- Interactive learning experience with progress tracking
- RAG-powered chatbot for content assistance
- Multilingual support (English and Urdu)
- Responsive design for all devices
- Code playground integration
- Video and image demonstrations

## Installation

```bash
npm install
```

## Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

## Deployment

The site is configured for GitHub Pages deployment. Use the following command:

```bash
npm run deploy
```
